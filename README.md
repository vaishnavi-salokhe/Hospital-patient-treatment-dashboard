# Hospital Patient Treatment Dashboard

An interactive Power BI dashboard built to analyze hospital treatment demand, treatment costs, hospital stay duration, and recovery outcomes.

## Project Objective

The purpose of this project is to help a hospital operations manager understand:

- Which departments treat the most patients
- Which treatment types have the highest average treatment cost
- Which departments have longer average hospital stays
- Which departments have higher or lower average recovery scores
- How results change by department, treatment type, and gender

![Dashboard preview](Hospital%20Patient%20Treatment%20dashboard-preview.png)

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- CSV dataset

## Key Metrics

- Total Patients
- Total Treatment Cost
- Average Treatment Cost
- Average Hospital Stay
- Average Recovery Score

## Key Insights

- Gastroenterology treated the highest number of patients.
- Surgery had the highest average treatment cost.
- Oncology had the longest average hospital stay.
- Pediatrics had the highest average recovery score.
- Neurology had the lowest average recovery score.
